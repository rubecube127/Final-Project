Three snapshots a year

At AoPS Academy, a campus director observes each instructor three times per year and coaches them afterwards. It is the main way teaching improves.

I was that director, with five classes of my own. The observations were the first thing squeezed — and I knew the instructors needed more than I could give them.

Not another chatbot on a transcript

You can paste a session into ChatGPT. Four things are missing, and they are the four that decide whether a director puts this in front of staff.

  • Nothing checks the quotes. Here every quote must be a literal substring of the transcript, and must actually support the score it was cited for.
  • Nothing is remembered — and nothing should be. Scores persist per instructor; transcripts and quotes never do.
  • There is no stopping rule. A child-welfare disclosure halts the run before any scoring happens.
  • There is no aggregate. A weekly digest names who needs a check-in and what the next PD should cover.

Talk-analytics tools (TeachFX) measure how much each person spoke. Video coaching platforms (Edthena) still consume the scarce resource: the coach's hours.

Ten stages — five never call a model

Anything a rule can decide, a rule decides — so it can be unit-tested. The model proposes; plain JavaScript disposes. All agents run on GPT-6-luna via Portkey.

The defence that matters most

An ordinary session. The student is getting everything right. Then one line in the middle of it — and the conversation carries straight on.

No scores. No coaching note. The pipeline stops after the scrub stage and returns escalation guidance instead.

It costs $0.0000 and zero tokens: a phrase list catches it before any model call, so the stopping rule does not depend on the model being reachable.

Also built: PII scrubbed before any model call; prompt injection flagged and ignored (a transcript demanding “rate this a 5” scored 3/4/1/1/3); a 20,000-character cap so a pasted PDF cannot burn the budget.

What I'd do next

  • Run a full term. The loop this is built around — set a focus, coach toward it, measure whether it moved — needs months, and has not been proven with real instructors yet.
  • Put a number on the scrubbing. Seed transcripts with known fake names and report the leak rate before and after.
  • Calibrate against humans. Two directors scoring the same transcripts independently would show whether the rubric scores mean anything.
  • Widen the maths checker beyond quadratics, and handle scanned PDFs.

Known limits: JSON storage, no password reset or rate limiting, partial maths coverage, one subject.
